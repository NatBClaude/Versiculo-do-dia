# Versículo do Dia

App estático que exibe um versículo bíblico diferente a cada dia, com sugestão de louvor relacionado.

- **Versículo do dia**: calculado pela data, é o mesmo para todos no mesmo dia.
- **Outro versículo**: sorteia um versículo aleatório da lista.
- **Copiar**: copia o versículo e a sugestão de música.
- **Favoritar**: salva versículos favoritos no navegador (localStorage).

Publicado automaticamente no GitHub Pages a cada push na branch `Claude`.
